# Example data

`3dpf_protein.pdb` and `3dpf_ligand.sdf` are inherited from the
DiffDock-Pocket example.

`6PEK/` is a compact smoke-test bundle derived from PDB 6PEK / EMDB EMD-20327:
processed receptor, ligand chemistry, precomputed ring features, and a local
map crop. The deposited ligand centroid `(99.5225, 129.031, 141.351)` is used
only to define the known-pocket Local smoke-test input. It must not be described
as a blind pocket-finding example. Confirm the redistribution terms and add the
PDB/EMDB download URLs to the release record before publishing.
