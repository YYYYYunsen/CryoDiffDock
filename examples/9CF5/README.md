# 9CF5 known-pocket example

The receptor and corrected deposited ligand are from the CryoLigandDB
processed test inputs for [PDB 9CF5](https://www.rcsb.org/structure/9CF5).
The density crop is the Figure 2 benchmark's Cartesian crop of
[EMD-45530](https://www.ebi.ac.uk/emdb/EMD-45530), with the same soft protein mask.

The predefined pocket center is the deposited ligand heavy-atom centroid. The
demo builds an input from ligand chemistry and uses the deposited 3D coordinates
for RMSD evaluation after docking. The archived Local benchmark RMSD is 1.2437 Å.
The report shows the actual RMSD of the new run separately.

The source archives publish their data under CC0. See the
[wwPDB usage policy](https://www.wwpdb.org/about/usage-policies) and
[EMBL-EBI public data-access statement](https://www.ebi.ac.uk/pdbe/about/public-data-access-statement).
